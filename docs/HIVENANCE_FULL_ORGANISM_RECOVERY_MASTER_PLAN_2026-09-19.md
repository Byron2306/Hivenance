# HiveNance Full Organism Recovery Master Plan

Date: 2026-09-19  
Branch: `hivenance-phoenix-edge-ecology`  
Status: FROZEN IMPLEMENTATION PROGRAMME  
Authority: public-market research only; execution and promotion remain false.

## Programme objective

Recompose HiveNance into **one causally auditable research organism** whose final directional conclusions are based on the full intended architecture rather than a reduced subset of available organs.

The programme exists because the repository already contains substantial capability across Phoenix, MarketMemory, Horizon, the CEX multi-horizon oracle, RegimeOracle, Edge Ecology, Comparison, WorldGraph, VNS/Polyphia, ConductingQueen, workers, crystals, learning, Pollen and causal settlement, but those capabilities are not yet all wired into one timestamp-bound prospective decision loop.

The target organism is:

```
PUBLIC MARKET
   ↓
canonical timestamped observation
   ↓
MarketMemory + CanonicalScoreFrame
   ↓
WorldState / Horizon lattice / CEX multi-horizon oracle
   ↓
WorldGraph
   ├─ Temporal Participation
   ├─ Flow
   ├─ Liquidity
   ├─ Volatility
   ├─ Cross-Market
   ├─ Path Geometry
   ├─ Regime
   ├─ Comparison
   ├─ CoinSelector selected + rejected universe
   ├─ Workers
   ├─ Crystal / Learning memory
   ├─ Medium-horizon trend
   └─ Derivatives/carry only where source-valid
   ↓
VNS / motif / texture / harmony / counterpoint
   ↓
Polyphonic Quorum
   ↓
Triune + ConductingQueen
   ↕
bounded research requests / graph recurrence
   ↓
immutable Hypothesis Envelope
   ↓
Phoenix freeze
   ↓
prospective settlement
   ↓
causal ablation + learning
```

## Non-negotiable programme rules

1. **No phase skipping.**
2. **No post-hoc threshold tuning inside a frozen experiment.**
3. **No historical evidence may be relabelled prospective.**
4. **No execution or promotion authority may be introduced by this programme.**
5. **No private exchange endpoint or credential is required for the research path.**
6. **Every organ must earn its runtime status:** AVAILABLE -> INVOKED -> INFLUENTIAL -> HISTORICALLY_USEFUL -> PROSPECTIVELY_USEFUL.
7. **Presence is not influence.** A running organ with zero decision effect is not considered causally active.
8. **Different transforms do not imply independent evidence.**
9. **Synthetic Mystique/VNS challenge worlds never count as observed evidence roots.**
10. **Same-root transforms cannot manufacture quorum.**
11. **Every phase must produce an explicit receipt, tests, and operator-visible status.**
12. **The current G1 campaigns and settlements remain immutable historical evidence.**
13. **A phase is not complete because code exists. It is complete only when the canonical runtime invokes it and the phase exit tests pass.**
14. **If an integration is unavailable because source data is unavailable, mark it explicitly unavailable. Do not fabricate it.**
15. **Every final research conclusion must remain reproducible from stored inputs and digests.**
