## Implemented Boundary

New Hivenance route damping is research-selection only:

- It cannot authorize live execution.
- It cannot submit orders.
- It temporarily suppresses routes whose recent admission or execution evidence is bad.
- Penalties decay over time, so recovered routes can re-enter.
- Route identity binds worker/model, thesis, regime, cohort, symbol class, symbol, horizon, direction, policy, and scenario.

Calibration-exploration fallback is also research-only:

- It activates only when the formal Phase-3 candidate gate returns zero candidates.
- It selects replay candidates from forecast-time fields only, then joins outcomes only for deterministic simulation.
- It labels every fallback candidate `execution_eligible=false`.
- It is designed to generate learning evidence, not to bypass promotion gates.
